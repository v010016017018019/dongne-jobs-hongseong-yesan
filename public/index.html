가까운 일자리 찾는 방법

  1. 최신 목록 확인

    정기적으로 확인한 사람인·잡코리아·고용24의 공고를 불러옵니다. 필터로 사이트와 지역을 선택할 수 있습니다. 마지막 원문 확인 시각과 실패 여부는 검증 기록에서 확인하세요.

  2. 지도에서 근무지 확인

    마커나 공고의 ‘위치 보기’를 누르세요. 주소와 좌표가 없는 공고는 위치 확인이 필요하다고 표시합니다.

  3. 원문을 열고 지원

    각 공고의 원문 버튼으로 채용 상세내용을 확인하고, ‘네이버 지도에서 보기’로 주변 교통을 살펴보세요.

API 키와 결제 등록이 필요 없습니다. 검색 결과의 마지막 페이지까지 확인하며 안전 상한은 군별 100페이지입니다. 조회 기록이 저장되어 중단되면 완료로 표시하지 않습니다. 최신 목록 확인 버튼은 게시된 자료를 다시 불러옵니다. 검증 기록에서 원문·상세 확인 수를 볼 수 있습니다.

같은 원문 묶기는 공개된 원문 링크로 동일 공고가 확인될 때 적용합니다. 주소 대조 위치는 동일 도로명·건물번호의 공개 좌표를 재사용하고 상세 카드에 근거를 표시합니다. 기준점 거리는 직선거리입니다. 지도에서 기준점을 직접 지정하세요.

온라인 버전은 정기 수집한 공고를 표시합니다. 예약 실행은 지연될 수 있으며, 마지막 목록 성공 시각과 상세 확인 시각은 검증 기록에서 확인하세요. 원문 접속 확인이나 오류가 생기면 기존 자료를 보존합니다. 신규는 사이트 등록일이 아니라 이 앱에서 처음 발견한 뒤 7일 동안 표시합니다.

V7는 검색 조건 저장, 지난 방문 이후 공고, 읽음 표시, 급여·고용형태·학력 복수 선택 필터, 지원 상태·메모, 변경·종료 이력을 제공합니다. 첫 방문에는 비교할 이전 방문이 없으며 30분 이내 새로고침은 같은 방문으로 취급합니다. 검색 조건 저장 시 지도 기준점도 이 브라우저에 저장합니다. 변경 이력은 기존 V5에서 이어진 기록 시작 이후 확인된 변화만 보여 주며, 목록에서 사라졌다는 이유만으로 마감됐다고 표시하지 않습니다.

학력은 여러 개 선택할 수 있습니다. 고졸 기준 선택은 학력무관·중졸 이하·고졸을 선택하며, 고졸 이상과 고졸부터 시작하는 범위도 포함합니다. 초대졸·대졸·대학원 학위가 최소 조건인 공고는 제외합니다. 학력 미기재·조건 해석 불가·원문별 조건 불일치는 학력 확인 필요로 구분합니다. 학력 선택도 검색 조건에 저장됩니다. 카드와 상세에는 학력 원문을 표시합니다.

무료 지도는 OpenStreetMap을 사용합니다. 현재 보는 화면의 지도만 불러오며 출처를 표시합니다. 지도 이용정책

공고·위치 검증 기록

마지막 수집 결과를 다시 불러옵니다. 개별 지원 조건과 마감 여부는 각 공고 원문에서 확인하세요.

채용공고 직접 등록

공개 조회가 어려운 공고를 링크로 추가할 수 있습니다. 등록한 공고와 직접 지정한 위치는 이 브라우저에만 저장됩니다.

관심·지원 관리

메모와 지원 상태는 이 브라우저에만 저장합니다. 다른 사람과 공유되지 않습니다. 각 공고의 저장 버튼을 누르세요. 종료되거나 목록에서 사라진 공고도 관리할 수 있습니다.
