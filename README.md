# 홍성·예산 채용지도 V7

사람인·잡코리아·고용24의 공개 채용공고를 무료 지도에서 확인하는 개인용 웹사이트입니다. 학력 복수 선택, 고졸 기준 선택, 지역·급여·경력 필터와 네이버 지도·공고 원문 연결을 지원합니다.

V7은 **Vercel Hobby에서 웹사이트를 제공하고 GitHub Actions에서 6시간 간격으로 공개 공고를 확인**합니다. PC가 꺼져 있어도 예약 작업은 GitHub에서 실행됩니다. 기존 V6 로컬 앱은 별도 폴더에 보존됩니다.

## 내 기록

관심공고·읽음·검색 조건·지원 상태·메모·직접 등록 공고·직접 지정 위치는 **현재 브라우저의 저장 공간에만 저장**합니다. 로그인이나 별도 데이터베이스가 필요하지 않습니다. 네트워크로 전송하지 않으며 다른 사람이나 다른 기기와 공유되지 않습니다. 브라우저 데이터를 삭제하거나 다른 브라우저·기기로 열면 개인 기록이 이어지지 않습니다.

기존 V6의 개인 기록은 자동으로 가져오거나 공개하지 않습니다. 공개 배포 결과물은 `dist`에 생성되며 개인 기록 파일·수집 서버 소스·환경변수 파일은 포함하지 않습니다.

## 학력 선택

학력무관·중졸 이하·고졸·초대졸(2·3년)·대졸(4년)·석사·박사·학력 확인 필요 중 여러 개를 선택합니다. 선택한 조건 중 하나라도 맞으면 표시합니다. 선택이 없으면 전체입니다.

**고졸 기준 선택**은 학력무관·중졸 이하·고졸을 함께 선택합니다. 고졸 이상과 고졸부터 시작하는 범위도 포함하며 초대졸 이상·대졸 이상처럼 최소 학력이 더 높은 공고는 제외합니다. 학력 외 경력·전공·자격증 등은 원문에서 확인하세요. 우대 조건과 필수 학력은 다릅니다.

## 공고 갱신과 확인

- GitHub Actions의 `Refresh public job listings`가 UTC 00:23·06:23·12:23·18:23, 한국 시간 09:23·15:23·21:23·03:23에 예약 실행됩니다. 실행은 지연되거나 누락될 수 있습니다.
- 수집한 공개 자료를 저장소에 반영하면 Vercel Git 연동이 새 웹사이트를 배포합니다. **최신 목록 확인**은 게시된 자료를 다시 불러옵니다.
- 원문 목록을 끝까지 확인하지 못하면 기존 목록을 유지합니다. 보안문자·접속 확인을 요청하면 해당 사이트 자동 조회를 멈추고 확인 필요 상태를 남깁니다. 인증이나 접근 제한을 우회하지 않습니다.
- 사람인·고용24 요청은 최소 1.2초, 잡코리아 요청은 최소 3.5초 간격입니다. 정상 상세 자료는 24시간 재사용하고 새 공고와 오류 자료를 우선 확인합니다.
- 정상 확인한 다른 사이트 자료는 일부 사이트 오류가 있어도 보존합니다. 검증 기록에는 마지막 성공 시각과 오류를 표시합니다.
- 마감 시간이 지나면 새 배포를 기다리지 않고 화면에서 제외합니다. 관심·지원 중인 공고의 메모와 공개 원문 정보는 현재 브라우저에서 보관합니다.
- 신규 표시는 채용사이트 등록일이 아니라 이 앱에서 처음 발견한 뒤 7일을 뜻합니다.

갱신되지 않는다면 저장소의 Actions 기록과 사이트의 검증 기록을 확인하세요. 공개 저장소에 60일 동안 활동이 없으면 GitHub가 예약 실행을 비활성화할 수 있습니다. GitHub의 `Run workflow`로 수동 실행할 수 있습니다.

## Vercel 배포

1. 이 폴더를 개인 GitHub 계정의 공개 저장소에 올립니다. 공개 공고 자료만 포함하며 개인 기록·`.env`·`.vercel`은 `.gitignore`로 제외합니다.
2. Vercel 무료 Hobby 계정에서 해당 GitHub 저장소 하나만 연결하고 Import합니다. Pro 체험이나 유료 추가 기능은 필요하지 않습니다.
3. 프레임워크는 Other, 빌드는 `npm run build`, 출력 폴더는 `dist`입니다. `vercel.json`에 설정되어 있습니다. Node.js는 22를 사용합니다.
4. `site.config.json`에 저장소 URL과 `updatesEnabled: true`를 설정합니다. 예약 작업과 Vercel Git 연동이 연결된 뒤 사용합니다.

Vercel은 개인·비상업용 Hobby 무료 한도 안에서 사용합니다. 별도 유료 지도 API나 사용자 데이터베이스를 추가하지 않습니다. GitHub Actions는 공개 저장소의 표준 실행 환경을 사용합니다. 외부 채용사이트가 클라우드 IP에서 조회를 제한할 수 있으며 오류 시 기존 자료와 실패 기록을 유지합니다.

## 로컬 미리보기

Node.js 22와 npm이 필요합니다.

```powershell
npm ci --ignore-scripts
npm run build
npm start
```

`http://localhost:4327/`을 엽니다. `start.cmd`로도 빌드 후 실행할 수 있습니다. 종료는 Ctrl+C입니다. 미리보기는 클라우드와 동일한 `dist`만 제공합니다.

로컬 수집은 `npm run collect` 이후 `npm run build`를 실행합니다. 기존 V6 자료를 수정하지 않고 V7의 자료만 갱신합니다.

## 검증

`npm test`는 임시 자료로 기존 학력·급여·위치·수집기 기능과 브라우저 저장 지속, 기기별 기록 분리, 개인 기록 미전송, 마감 후 보관, 제휴 원문 키 변경, 저장 실패, 공개 배포 필드를 검증합니다.
